# Grok 4.6 Model Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** xAI Grok 4.6 を `global.xai.grok-4.6` 経由で呼び出せる選択可能モデルとして登録する。

**Architecture:** 既存のモデルファミリ分岐機構（`is_nova_model` / `is_gpt_oss_model` などと同列に `is_grok_model` を追加）と `GLOBAL_INFERENCE_PROFILES` によるプロファイル解決機構をそのまま利用する。Grok はオンデマンドスループット非対応のため、`get_model_id` に「プロファイル必須モデル」の概念を新設し、環境変数フラグの状態に関わらず素のモデルIDへフォールバックさせない。推論パラメータは Grok が `temperature` / `topP` / `stopSequences` を拒否するため `maxTokens` のみを送り、reasoning の深さは `additionalModelRequestFields` の `reasoning.effort` で指定する。

**Tech Stack:** Python 3 / Pydantic / boto3（bedrock-runtime Converse API）/ unittest + pytest、TypeScript / React / zustand / i18next / vitest

## Global Constraints

- モデルキーは `grok-4.6`。`toCamelCase`（`frontend/src/utils/StringUtils.ts`）を通すと `grok46` になり既存 `ActiveModels` キーと衝突しない
- Bedrock のベースモデルIDは `xai.grok-4.6`。素のこのIDでは呼び出せず、必ず推論プロファイル経由で呼ぶ
- Global クロスリージョン推論プロファイルは `global.xai.grok-4.6`、Geo（US ジオ）は `us.xai.grok-4.6`
- reasoning effort のフィールド形式は `{"reasoning": {"effort": <値>}}` のみ。`reasoning_effort` という綴りは無視されるため使用しない
- reasoning effort の既定値は `"low"`（Bedrock 側の既定値と一致）
- 料金は Global クロスリージョン推論の値。既存定義と同じ USD / 1,000 トークン単位で入力 `0.002`、出力 `0.006`
- `temperature` / `topP` / `stopSequences` / `document` / プロンプトキャッシュは Grok が拒否するため一切送らない
- i18n の更新対象は `en` / `es` / `ja` の3言語のみ（直近の GPT-OSS 追加と同じ範囲）
- CDK の変更は行わない

```python
def _prepare_grok_model_params(
    model: type_model_name, generation_params: Optional[GenerationParamsModel] = None
) -> ConverseConfiguration:
    """
    Prepare inference configuration for xAI Grok models.

    Grok rejects temperature, topP and stopSequences outright, so only maxTokens
    is passed. Reasoning is always active and its depth is controlled through
    the model-specific `reasoning.effort` field.
    """
    inference_config: InferenceConfiguration = {
        "maxTokens": (
            generation_params.max_tokens
            if generation_params
            else DEFAULT_GENERATION_CONFIG["max_tokens"]
        ),
    }

    return {
        "inferenceConfig": inference_config,
        "additionalModelRequestFields": {
            "reasoning": {"effort": GROK_REASONING_EFFORT},
        },
    }
```
